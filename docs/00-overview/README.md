# 项目总览

## 目标

本次工作不是对现有镜像站进行局部修补，而是重新设计整个 LZU Mirror 系统，包括主机、存储、同步控制面、下载数据面、网络、安全、可观测性、前端以及长期运维体系。

总体分层：

```text
Platform / OS
    ↓
Storage
    ↓
Control Plane (LMT)
    ↓
Serving (Nginx)
    ↓
Frontend

横向能力：
Observability
Security
Backup / DR
Operations
```

## 核心原则

1. **职责分离**：LMT 负责同步控制与发布，Nginx 负责下载数据面，文件系统只提供稳定的本地存储语义。
2. **可重建数据与关键状态分离**：镜像内容可以重新从上游获取，不为其投入大规模冗余；系统配置、控制面数据库、凭据等小体量关键状态需要更强保护。
3. **优先简单可解释的基础设施**：能够由 Linux、systemd 和成熟文件系统直接完成的事情，不额外引入复杂编排层。
4. **允许停站重构**：本次迁移不以零停机为目标，优先保证迁移过程可验证、可恢复。
5. **设计与实现分离**：本仓库记录整个系统的设计事实；组件内部实现细节留在各自代码仓库。
